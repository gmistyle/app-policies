# app-policies

各產品／服務的公開說明頁面（GitHub Pages），例如隱私權政策、支援頁、服務條款、產品介紹。適用於 App、後台系統（CRM backstage）或其他軟體服務。

此 repo 為公開，請勿放入任何機密或程式碼。

## 結構

每個產品一個子資料夾，網址為 `https://gmistyle.github.io/app-policies/<資料夾>/`。

- `breathe/`：呼吸計時器
- `bottingpass/`：BottingPass 軟體授權介紹頁

## 新增產品

1. 建立新資料夾（英文小寫，網址交出去後不要再改）。
2. 放入 `index.html`，視需要加入 `privacy.html`、`support.html`、`terms.html` 等。
3. 在本檔「結構」清單補上一行。
